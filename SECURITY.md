| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security and integrity of the WATT / Nationalfreie Tage web platform and slogan generator seriously.

If you believe you have discovered a security vulnerability or supply chain issue:

1. **Do not create a public GitHub issue.**
2. Please report the vulnerability privately via [GitHub Private Vulnerability Reporting](https://github.com/niStee/watteuropa-web/security/advisories/new) or by sending an email to:
   - `52573120+niStee@users.noreply.github.com`
3. Please include:
   - Description of the vulnerability and affected components
   - Steps to reproduce or proof of concept
   - Potential impact
4. You will receive an acknowledgment of your report within 48 hours.

Thank you for helping keep the WATT project safe and open for everyone.
